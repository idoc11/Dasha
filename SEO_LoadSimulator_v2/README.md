# SEO_LoadSimulator v2 – симулятор нагрузки СЭО МФЦ с базой данных и ролями

Доработка программы SEO_LoadSimulator: расчётное ядро и состав параметров сохранены, добавлены вход по ролям,
база данных PostgreSQL, сохранённые сценарии и история расчётов, администрирование пользователей.

## Файлы
| Файл | Назначение |
|---|---|
| `Model.cs` | Имитационная модель (восстановлена из вашего SEO_LoadSimulator.exe): поток, очередь по приоритетам, статистика, усреднение по дням |
| `Db.cs` | Работа с БД: вход, пароли (PBKDF2), сценарии, история, пользователи |
| `MainForm.cs` | Главное окно: параметры, расчёт, подбор окон, отчёт CSV, меню |
| `Dialogs.cs` | Вход, сценарии, история расчётов, пользователи |
| `ChartBox.cs` | Графики |
| `Program.cs` | Точка входа (сначала окно входа) |
| `sql/sim_schema.sql`, `sql/sim_seed.sql` | Схема БД (4 таблицы) и тестовые данные (3 пользователя, 5 сценариев, 16 записей истории) |

## Запуск
1. Установить PostgreSQL 14+ и .NET SDK 8.
2. `createdb simdb`, затем `psql -d simdb -f sql/sim_schema.sql -f sql/sim_seed.sql`
3. При необходимости строка подключения: `set SIM_DB=Host=localhost;Database=simdb;Username=postgres;Password=ВАШ_ПАРОЛЬ`
4. `dotnet run` в папке проекта (или собрать в Visual Studio).

## Что осталось как в исходной программе
Параметры и их диапазоны, значения по умолчанию, закон времени обслуживания, стресс-режим, подбор окон (деление пополам, не менее 5 прогонов),
сообщения об ошибках, формат отчёта CSV. Начальное значение ГСЧ i-го дня = начальное + i × 7919.

## Проверка
Модель перенесена так, что при начальном числе 2026 и 100 прогонах даёт те же числа, что и ваш исходный exe
(например, 1000 чел./сут, 22 окна: 99,0 % талонов в норме; стресс-режим: 69,8 %; подбор в стресс-режиме: 24 окна).
Сверка выполнена на копии модели вне C#. Сам проект на C# не компилировался в среде подготовки.
